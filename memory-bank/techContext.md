# Tech Context: CALYBK Website

## Technology Stack

### Core Framework
- **Astro**: Static site generator with island architecture
- **TypeScript**: For type safety

### Styling
- **TailwindCSS**: Utility-first CSS framework
- **Optional**: shadcn/ui or Radix UI for components

### Design System
- **Primary Color**: #6cf20d (Bright Green)
- **Background Light**: #f7f8f5
- **Background Dark**: #172210
- **Font Family**: Inter
- **Icons**: Material Symbols
- **Organic Shapes**: CSS border-radius for blob effects

### Development Tools
- **VS Code**: Primary IDE
- **Git**: Version control
- **npm/pnpm**: Package manager

### Deployment
- **Cloudflare Pages**: Primary hosting platform
- **Build Command**: `npm run build`
- **Output Directory**: `dist`

## Constraints
- Static site only (no server-side rendering required initially)
- Mobile-first responsive design
- Performance optimized
