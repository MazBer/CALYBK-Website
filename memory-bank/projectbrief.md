# Project Brief: CALYBK Website

## Overview
A website for CALYBK (Life Sciences Club) at **Cağaloğlu Anadolu Lisesi** to share posts, news, and magazines.

## Target Users
- Club members (students)
- Students interested in life sciences
- School community
- General public

## Design
- **Primary Color**: #6cf20d (Bright Green)
- **Light Background**: #f7f8f5
- **Dark Background**: #172210
- **Font**: Inter
- **Icons**: Material Symbols
- Modern, organic shapes with rounded corners
- Dark mode support

## Core Requirements

### Content Types
- **Posts**: Articles and blog content
- **News**: Updates and announcements
- **Magazines**: Published magazine issues

### Technical Stack (Proposed)
- **Framework**: Astro (static site generator with excellent content support)
- **Styling**: TailwindCSS
- **Deployment**: TBD

## Project Details
- **Primary Language**: Turkish (website content) | English (development)
- **Future**: Multi-language support (English planned)
- **Hosting**: Cloudflare Pages

## Goals
- Easy content management
- Fast, modern website
- Mobile responsive
- Clean, professional design suitable for a school club
